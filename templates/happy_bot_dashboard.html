Protection tools

Auto-Mod

Stops spam, invite links, scam links and blocked words. Open it with ,automod.

Anti-Nuke

Stops anyone from deleting channels, roles or members in a hurry. Only trusted people can change it.

Anti-Raid

Spots a sudden flood of new members and acts at once. You can also start raid mode by hand.

Fake Perms

Let a role use bot commands without giving real server power.

Good habits

  • Keep Happy's role high in your role list so it can act.
  • Only trust people you know well. Trusted people are never stopped.
  • Set a log channel so you can see what happened.
  • Never share your bot token or database link with anyone.

Get started

1
Install what the bot needs

Run pip install -r requirements.txt.

2
Add your keys

Put them in a .env file. Keep that file private and never share it.

3
Start the bot

Run python main.py.

4
Set up your server

Type ,quicksetup in your server, then ,help to explore.
